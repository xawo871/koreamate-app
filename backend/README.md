# Backend

This directory is the backend placeholder for KoreaMate.

## Planned responsibilities

- authentication and user governance
- subscription and payment validation
- learning session and progress APIs
- AI service orchestration
- admin and analytics endpoints
- async job processing and OCR pipelines

## Recommended stack

- REST or GraphQL API service
- PostgreSQL for persistence
- secure secret management
- queue worker and scheduler
- monitoring and audit logging

## Current state

This is intentionally a scaffold. It will be expanded as Phase 1 and later phases are implemented.
